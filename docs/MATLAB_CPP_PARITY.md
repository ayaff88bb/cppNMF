## 结论

在当前输入和完全一致的 reference 参数下，MATLAB 函数化参考实现与 C++
实现的结果可判定为**浮点误差范围内数值一致**。STFT、NNDSVD、三层 DNMF
物理子空间、求解器重构以及最终 4 个软掩膜子空间均通过验证。

验证没有假设两个实现使用相同的子空间编号。每层先计算累计基向量与相应激活
向量的外积贡献，再以外积余弦相似度做一对一最优匹配。当前数据上，最优映射
恰好全部为同编号映射。

## NNDSVD 确定性

MATLAB 中连续执行两次 NNDSVD，`W` 和 `H` 的相对误差均为 0；本次数据上未
观察到随机初始化干扰。MATLAB `svds` 和 Eigen `BDCSVD` 得到的 NNDSVD
初始化重构矩阵相对误差为 `7.37e-15`。

仍需区分两个概念：NNDSVD 不使用随机填充，说明同一实现通常可复现；不同
SVD 后端在奇异值退化或接近退化时仍可能选取不同的等价奇异子空间。因此项目
采用排列无关的物理分量匹配，而不是把“NNDSVD”本身当作跨库逐元素一致的
充分证明。

## 判定阈值与复现

- STFT/前端严格阈值：相对误差 ≤ `1e-10`
- DNMF 数值等价阈值：匹配子空间能量加权相对误差 ≤ `1e-6`
- DNMF 工程等价阈值：匹配子空间能量加权相对误差 ≤ `1e-3`
