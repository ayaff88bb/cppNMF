# 验证说明

## 验证策略

项目将验证分成三层：

1. 单元测试检查参数边界、维度、非负性和窗口公式。
2. 算法性质测试检查 STFT 往返误差、NMF 目标下降和软掩膜分区。
3. MATLAB golden tests 使用公开的 20,000 点合成冲击信号，检查跨语言数值一致性。

## 公开 MATLAB golden data

运行以下命令可重新生成基准：

```powershell
matlab -batch "addpath('validation'); export_cpp_stft_golden"
```

MATLAB 只用于离线生成验收数据；`cppnmf_cli.exe` 不链接也不调用 MATLAB。
导出的文件位于 `validation/public_golden/`，包括原始合成信号、预处理信号、周期窗、ISTFT
结果、复数 STFT 签名、q_NSD 汇总和 MO 压缩签名。

生成器不读取研究 `.mat` 文件，也不使用随机数，因此公开仓库和 CI 能够稳定
复现相同基准。真实研究样本的全量对照属于另一条本机验证链路，其派生文件不
随公开仓库发布。

## 已验证结果

Release 构建下 `ctest --preset windows-msvc-release`：16/16 通过。

跨语言测试覆盖：

- 采样率 20 kHz、20,000 个样本
- 1024 点 FFT、120 点周期 Hamming 窗、20 点 hop
- 幅值矩阵 512×995，无尾部补零
- 9 个代表频点 × 9 个代表帧的复数谱和坐标轴
- 20,000 点恒等幅值 ISTFT
- `E_TF`、`C_per`、`D_per`、`F_flat` 和最终 `q_NSD`
- 81 个 MO 压缩矩阵采样值

FFT 与特征指标使用 `1e-10` 量级容差。除此之外，项目现已加入 DNMF 全量
跨语言对照：两端均使用 reference 迭代预算，完整导出 NNDSVD、`W/H/S`、
累计基矩阵、各层重构和最终软掩膜子空间。比较时不直接假设列号相同，而以
“累计基向量 × 激活向量”的外积余弦为相似度，通过一对一最优分配匹配分量。

## 私有真实样本全量结果记录

以下是本机私有研究样本的历史验证结果。它用于证明 MATLAB/C++ 全量算法迁移
精度，但输入信号和派生矩阵均被 `.gitignore` 排除：

| 对象 | MATLAB/C++ 相对误差 |
|---|---:|
| STFT 幅值矩阵 | `1.456624e-15` |
| NNDSVD 初始化重构 | `7.372854e-15` |
| 第 1 层匹配子空间（能量加权） | `1.582609e-11` |
| 第 2 层匹配子空间（能量加权） | `2.132461e-11` |
| 第 3 层匹配子空间（能量加权） | `1.088387e-11` |
| 顶层软掩膜幅值子空间（能量加权） | `1.259636e-11` |
| 顶层时域子空间（能量加权） | `1.011428e-11` |
| 含 S 的求解器重构 | `1.544253e-12` |

所有层的匹配分量余弦均大于 `0.999999999999998`，当前样本的最优映射也恰好
是同编号映射。两端目标历史均有 23 个检查点，初值和终值相对误差分别约为
`9.87e-13` 和 `3.90e-13`。因此当前数据与参数下可判定为浮点误差范围内数值
一致。完整方法和可复现命令见 `validation/README.md`，实测报告见
`docs/MATLAB_CPP_PARITY.md`。

## 公开合成样本快速基线

命令：

```powershell
build/windows-msvc/cppnmf_cli.exe `
  --input validation/public_golden/raw_signal.csv `
  --sample-rate 20000 --preset quick `
  --output outputs/public_signal_quick
```

一次 Release 运行结果：

| 指标 | 数值 |
|---|---:|
| q_NSD | 0.347329 |
| STFT 尺寸 | 512×995 |
| DNMF 求解耗时 | 828.96 ms |
| 总耗时 | 921.66 ms |
| 求解目标起点 | 45519.82 |
| 求解目标终点 | 8231.71 |

计时受 CPU、编译器和后台负载影响，应在同一机器、同一 Release 配置下比较。
独立基准程序对 20,000 点合成冲击信号重复 3 次，本机中位数为求解器
1110.78 ms、端到端 1237.68 ms。
